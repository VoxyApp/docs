# Voxy - быстрый и удобный мессенджер для ежедневного общения

**Voxy** — это кроссплатформенное мобильное приложение-мессенджер, разрабатываемое с упором на безопасность, скорость работы и доступность на территории РФ. Проект нацелен на решение задач импортозамещения и предоставление пользователям высокого уровня защиты данных без блокировок и замедлений.

> **Статус проекта:** В разработке (Курсовой проект по дисциплине «Проектная деятельность 1», СибГИУ).

## Основные возможности

- **Личные и групповые чаты:** Обмен текстовыми сообщениями, эмодзи, стикерами и реакциями.
- **Отправка медиафайлов:** Передача изображений, документов и видео.
- **Безопасность:** Высокий уровень защиты данных (TLS 1.3 для транспортного уровня и шифрование БД).
- **Гибкие роли и права:** До 128 разрешений на роль в групповых чатах (администратор, модератор, участник).
- **Аудио- и видеозвонки:** Организация связи через сервер.
- **Управление профилем:** Настройки приватности и управление контактами.
- **Кроссплатформенность:** Планируется поддержка Android, iOS и десктоп-клиентов.
- **Доступность:** Работа на территории РФ без необходимости использования VPN.

## 🛠 Технический стек

Согласно Уставу проекта, разработка ведется с использованием следующих технологий:

- **Клиентская часть:** Egui (Rust)
- **Серверная часть:** Rust (Axum + Quin)
- **Протоколы передачи данных:** QUIC, собственный протокол на базе QUIC и MessagePack
- **Базы данных:** 
  - PostgreSQL (метаданные, роли)
  - Scylla (хранение сообщений)
  - Valkey (кэширование)
- **Шифрование:** OpenSSL (TLS 1.3)
- **Инфраструктура:** Docker, облачный хостинг
- **Инструменты:** Git (GitHub), Figma, Zed, MS Project
